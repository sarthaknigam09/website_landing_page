# MoneyMapper — Smart Financial Mapping & Wealth Management

A high-converting, modern, responsive fintech landing page built with **React**, **Vite**, **TypeScript**, and **Tailwind CSS**.

--- 

## 🚀 Overview & Features
 
- **Section 01: Hero & Sticky Navigation**
  - Transparent blur glassmorphic navbar with active nav items, Login, and Get Started triggers.
  - Value proposition headline with brand purple-to-magenta gradient.
  - CSS-only realistic 3D smartphone mockup with Financial Fitness Score gauge, Net Financial Position sparkline, and Live 24K Gold Rate.
  - Interactive feature pills and social proof indicators.
- **Section 02: 5 Financial Pillars & Live Dashboard**
  - Holistic 5-pillar grid (Stock & Investment, Mutual Funds, Insurance, Emergency Fund, Goals & Planning).
  - High-fidelity interactive desktop dashboard preview with time-filter controls and realistic market trend graphs.
- **Section 03: AI Assistant & Conversational Chat**
  - Two-column layout showcasing key benefits and a live interactive chat card featuring the MoneyMapper blue robot mascot.
- **Section 04: Market Insights & Stock Picks**
  - Editorial news cards with high-res photographic gradients and source badges (Financial Express, MoneyControl, Bloomberg).
  - MoneyMapper stock ticker row with live price indicators and market volatility sparklines.
- **Section 05: Conversion CTA & Footer**
  - High-impact two-column CTA banner with tilted phone mockup.
  - Comprehensive sitemap footer with brand social links, Product/Company/Support columns, and SSL/Data Protected security badges.
- **Global Coming Soon Modal**
  - Universal interactive modal triggered on every button, link, social icon, and pill across the page with contextual feature labels.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite 6
- **Language**: TypeScript
- **Styling**: Tailwind CSS 3.4
- **Icons**: Lucide React + Custom Lucide-styled brand SVGs

## 📦 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/sarthaknigam09/website_landing_page.git
cd website_landing_page
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
The optimized production bundle will be generated in the `dist/` directory.
